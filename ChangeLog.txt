
This file tracks overall changes and fixes to the Engine.


# Version 0.2

    CHANGES

    - ConsoleOutputHandler and TextRenderingHandler now support loading ttf fonts and rendering
      them at different sizes.

    - Added an EventSystem

    - Reconfigured TextRenderingHandler to use SDL_ttf.

    - Upgraded SpriteHandler to now support layered rendering of Sprites.

    - Added a WeightDistribution class for generating random numbers with set probabilities.

    - Added a Tilemap class.

    - Added a CrashOutputHandler class for dumping exception context to a text file.

    FIXES

    - Fixed InputHandler not properly blocking keys after about a minute of simulation.

    - TextRenderingHandler and ConsoleOutputHandler now properly handle move and copy constructor
      functions, rather than using the default ones.

    - SDL_Renderer background is now properly being set by the init file. 

    - Fixed FrostRandom::generate_random_int seg faulting when the higher bound was less
      than the lower bound.
