Detailed Description

Provides the base infrastructure for more in depth UIItems to derive from. UIItems are used to create modular and recursive interfaces for users to interact with in a text-menu system.

Member Enumeration Documentation

◆ Status

enum UIItem::Status

Represents different states that a UIItem can exist in inside the simulation of the UIInterfaceTools' simulation. NO_STATUS means the UIItem has no status applied to it. HOVERED means that this item is currently hovered by the cursor, and SELECTED represents this item is currently being selected.
