Detailed Description

Tracks all Menus that are created along with handling and processing Menus that are active.

For a Menu's update() method to be processed each frame, it needs to be active. To activate a Menu, use the activate_menu() method. Deactivated Menus will be ignored, so the deactivate_menu() method should be called when a Menu should be put to "sleep".

When a Menu is activated, the MenuManager calls its start() method.
