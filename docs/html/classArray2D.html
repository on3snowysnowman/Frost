Detailed Description

template<typename T, uint64_t N>
class Array2D< T, N >

A fixed-size 2D array class template.

Provides a simple interface for managing a 2D array with compile-time dimensions. Supports direct access and bounds-checked access to elements.

Template Parameters
TThe type of elements stored in the array.
NThe size of each dimension (NxN array).
